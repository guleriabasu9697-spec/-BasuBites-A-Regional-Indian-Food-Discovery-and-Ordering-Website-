# BasuBites

**BasuBites** is a responsive restaurant discovery and food ordering demo inspired by Indian food delivery apps. Explore sample restaurants and dishes from North, South, East, and West India.

## Features

- Browse restaurants and search by restaurant name, cuisine, or description.
- Filter by Indian region: North, South, East, or West.
- Filter by rating, delivery time, vegetarian options, and offers.
- Open restaurant menus and add dishes to the cart.
- Adjust cart quantities and see an itemized price summary.
- Responsive layout for desktop and mobile screens.

## Run locally

1. Download or clone this folder.
2. Keep `index.html`, `style.css`, and `script.js` together.
3. Open `index.html` in a web browser.

No build tools or package installation are required.

## Project files

- `index.html` — page structure and content.
- `style.css` — visual design and responsive layout.
- `script.js` — restaurant filters, search, menus, and cart interactions.

## Demo limitations

This is a front-end demo. Restaurant data and prices are sample content; sign-in and checkout do not connect to real services. Photos and fonts load from online sources, so an internet connection is needed for those assets.

## Built with

HTML, CSS, and vanilla JavaScript.
